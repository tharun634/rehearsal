## Turn 2
**Barista:** Ima, watashi wa omocha o shimasu. Nani o kudasai?

**coach:** they got across
- `Katsu-men, please. Ah, one size large.` → `Katsu-men, one size large, please.` (politeness) — The ‘please’ is a polite addition that would improve the flow and sound more natural.
- `Katsu-men, one size large.` → `Katsu-men, one size large, onegaishimasu.` (politeness) — Adding ‘onegaishimasu’ (please) after the order makes the request more polite.
- `Katsu-men, one size large.` → `Katsu-men, one size large, arimasu ka?` (clarification) — It’s better to confirm if they have the size large available before ordering.
**say instead:** Katsu-men, one size large, onegaishimasu.
**coach nudge:** Could you please confirm if they have the large size available before you order?
